# DevOps Week 02

## Git Collaboration Workflow

This repository demonstrates a Git and GitHub collaboration workflow using branches, commits, pull requests, and merge conflict resolution.

## Work Completed

- Created and worked with Git feature branches.
- Created the `feature-config-update` branch.
- Added configuration and collaboration updates.
- Created a Pull Request from `feature-config-update` to `main`.
- Resolved a merge conflict in `collaboration.txt`.
- Committed and pushed the resolved changes.
- Merged the feature branch into the `main` branch.
